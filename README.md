# Markey Tech Solutions Website

Documentation for the Markey Tech Solutions business website project, using Google Sites for page authoring and Cloudflare for domain/DNS management.

**Brand:** Markey Tech Solutions (MTS)  
**Slogan:** “You turn it off, we turn it back on.”

## Project purpose

Present computer repair and IT services in a clear, approachable format and give prospective customers a way to learn about the business.

## Repository contents

- [Website architecture](docs/architecture.md)
- [Content and brand guide](docs/content-and-brand.md)

This is a documentation repository. Google Sites hosts the actual page layout and content; this repository is not an exported website, a replacement deployment, or a live synchronization of Google Sites. No administrative DNS export or account verification records are included.

Branding concepts included a modern white-background treatment, computer/network imagery, and profile/banner adaptations. Original artwork is not bundled in this release because the exact final asset set has not been established from the available project files.
